# Contribuindo com o Luvit

1. Instale as dependências seguindo o README.
2. Copie `.env.example` para `.env` e nunca versiona credenciais.
3. Execute `php artisan test` antes de enviar alterações.
4. Execute `npm run build` quando alterar a interface.
5. Escreva mensagens de commit curtas e em português.

As integrações externas devem continuar com cache, tratamento de indisponibilidade e fallback para dados locais.
